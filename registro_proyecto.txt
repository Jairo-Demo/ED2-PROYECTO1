# Registro de Desarrollo - Proyecto: Tres en Raya con Minimax y ML

## Semana 1 - Día 1: Configuración inicial y Arquitectura
- Configuración del repositorio local.
- Creación de la estructura de carpetas bajo el patrón MVC (model, view, controller).

## Semana 1 - Día 2: Lógica del Juego (Modelo)
- Se creó el archivo `model/game_model.py`.
- Se implementó la clase `TresEnRayaModel` definiendo el tablero como una matriz 3x3.
- Se implementaron los métodos solicitados: validación de movimientos válidos, registro de movimientos, comprobación de estado de victoria (filas, columnas, diagonales) y condición de empate.
- Todo el código respeta el estándar PEP 8 e incluye docstrings.
- Se incluyó preventivamente el método `deshacer_movimiento` para el Backtracking futuro.

## Semana 1 - Día 3: Interfaz Gráfica (Vista)
- Se creó el archivo `view/gui_view.py` utilizando la librería Tkinter.
- Se maquetó la clase `TresEnRayaView` dividiendo la ventana en dos marcos (Frames).
- Marco Izquierdo: Matriz de 3x3 con objetos `tk.Button` para el tablero interactivo.
- Marco Derecho: Panel lateral con `tk.LabelFrame` para mostrar el estado del juego (turnos, victorias).
- Se implementó la separación estricta de responsabilidades (MVC): la vista no importa al modelo, simplemente usa una función callback (`set_click_callback`) para enviar eventos de clic al futuro Controlador.

## Semana 1 - Día 4: Coordinación e Interacción (Controlador)
- Se creó el archivo `controller/game_controller.py`.
- Se implementó la clase `GameController` encargada de instanciar la conexión entre el Modelo y la Vista.
- Se desarrolló el método `manejar_clic` para procesar la interacción del usuario con las casillas.
- Se implementó la lógica de flujo de turnos, actualización visual sincrónica del tablero y detección de final de partida (victoria o empate) al ocurrir un evento.
- El código mantiene un enfoque didáctico con comentarios descriptivos paso a paso.

## Semana 1 - Día 5: Integración y Pruebas (Humano vs Humano)
- Se creó el archivo principal `main.py` en la raíz del proyecto.
- Se instanciaron los tres componentes principales (Modelo, Vista, Controlador) logrando la integración final del patrón MVC.
- Se realizaron pruebas exitosas de la modalidad "Humano vs Humano".
- El juego valida correctamente los clics, los turnos, las victorias y los empates.
- Con esto se da por finalizada exitosamente la Semana 1 del proyecto.
